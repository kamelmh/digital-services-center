# Digital Services Center — Design System

## Brand Identity

### Logo Variants
| Variant | File | Use Case |
|---------|------|----------|
| **Hexagon Clean** | `assets/images/logo-hexagon-clean.png` | Profile pictures, email signatures |
| **Hexagon Premium** | `assets/images/logo-hexagon-premium.png` | Hero images, banners, social media |
| **Square MK** | `assets/images/logo-square.png` | Small thumbnails, favicons |

### Color Palette
| Color | Hex | Use |
|-------|-----|-----|
| **Navy Blue** | #0A1628 | Primary background |
| **Gold** | #D4AF37 | Accent, highlights |
| **White** | #FFFFFF | Text on dark backgrounds |
| **Light Gray** | #F5F5F5 | Secondary backgrounds |
| **Dark Gray** | #333333 | Text on light backgrounds |

### Typography
| Font | Weight | Use |
|------|--------|-----|
| **Inter** | 400, 600, 700 | Body text, UI elements |
| **Playfair Display** | 700 | Headlines, logos |

### Logo Usage
- **Minimum size**: 32px height
- **Clear space**: 1x logo height on all sides
- **Background**: Always on navy or white

## File Naming Convention

```
dsc-[type]-[variant]-[size].[ext]
```

### Examples
- `dsc-businesscard-front-300dpi.png`
- `dsc-letterhead-a4.pdf`
- `dsc-invoice-template.xlsx`
- `dsc-social-instagram-1080x1080.png`
- `dsc-pricelist-a4-print.pdf`

---

## Export Settings

### Print (300 DPI)
- Business cards: 3.5 x 2 inches
- Letterhead: A4 (210 x 297 mm)
- Flyers: A4 (210 x 297 mm)

### Digital (72-144 DPI)
- Instagram: 1080 x 1080 px
- Facebook: 1200 x 630 px
- LinkedIn: 1200 x 627 px
- WhatsApp: 800 x 600 px
