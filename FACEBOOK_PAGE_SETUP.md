# DSC Facebook Page — Setup Guide

## Step 1: Create the Page (5 min)

1. Go to **facebook.com/pages/create**
2. Choose: **Business or Brand**
3. Fill in:
   - **Page Name**: `DSC — Digital Services Center`
   - **Category**: `Business Consultant` (or `Service à la clientèle`)
4. Click **Create Page**
