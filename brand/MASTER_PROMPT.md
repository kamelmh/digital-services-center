# DSC Signal Master Prompt

Use this prompt in Canva AI, Claude, ChatGPT, or any design tool to generate consistent DSC Signal brand assets.

## Logo Prompt

```
Create a minimalist logo for "DSC Signal" — a digital services company.

DESIGN:
- Bold uppercase letters "DSC" — thick, geometric, Space Grotesk Bold style
- D and C are navy #0A1628, S is gold #D4AF37
- S is slightly larger than D and C — it's the accent letter
- Add a thin navy #0A1628 square frame around the letters — 2-3px border
- Square format, centered, clean

BACKGROUND:
- Light version: White or #F5F5F0 background
- Dark version: Navy #0A1628 background with white D+C, gold S

STYLE:
- Flat, geometric, no gradients, no shadows, no 3D
- No extra elements — no dots, no nodes, no tagline
- Just DSC in a thin frame, centered

EXPORT:
- PNG, transparent background if possible
- Square format, at least 1080x1080px
```
