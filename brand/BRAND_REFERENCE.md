# DSC Signal Brand Reference

## Mark
- **Name**: DSC Signal
- **Type**: Lettermark with accent
- **Letters**: DSC (Digital Services Center)

## Colors
| Element | Hex | Usage |
|---------|-----|-------|
| Navy | #0A1628 | D and C letters, frames |
| Gold | #D4AF37 | S letter (accent) |
| Paper | #F5F5F0 | Light background |
| White | #FFFFFF | Dark mode background |

## Typography
- **Font**: Space Grotesk Bold (700)
- **Fallback**: Inter, sans-serif
- **Weight**: Bold only — no light/regular

## Variants
| File | Background | Letters | Use Case |
|------|-----------|---------|----------|
| `dsc-signal-primary.svg` | Light #F5F5F0 | Navy D+C, Gold S | Documents, print, light websites |
| `dsc-signal-dark.svg` | Dark #0A1628 | White D+C, Gold S | Social media, app headers, dark mode |
| `dsc-compact.svg` | Dark #0A1628 | Gold S only | Profile photo, avatar, favicon |
| `dsc-favicon.svg` | Dark #0A1628 | Gold S (32px) | Browser favicon |
| `dsc-canva-clean.svg` | White | Navy D+C, Gold S | Canva import (original paths) |

## Usage Rules
1. Gold S is always the accent — never swap colors
2. D and C are always the same color (navy or white)
3. Minimum size: 32px height for letters, 16px for compact
4. Clear space: equal to the stroke width of the D
5. No gradients, shadows, or 3D effects
6. No additional elements beyond DSC + frame

## Export Formats
- **SVG**: Primary (scalable, editable)
- **PNG**: For web/email (1080px+ recommended)
- **ICO**: Browser favicon (16px, 32px)
