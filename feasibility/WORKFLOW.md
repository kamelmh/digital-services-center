## PIPELINE COMPLET

```
Lead → Qualification → Fiche Client → Collecte → Validation → Modèle → Contrôle → Revue → Livraison → Suivi
```

---

## ÉTAPE 1: QUALIFICATION (20 minutes)

### Objectif
Déterminer si le projet est viable et si le client est un bon candidat.

### Questions de Qualification

| Question | Critère d'acceptation |
|----------|----------------------|
| Quel est votre projet? | Idée claire, pas vague |
| Quel est votre budget? | > 100,000 DZD |
| Avez-vous de l'expérience? | > 1 an ou formation |
| Avez-vous un local? | Oui ou en recherche active |
| Quand voulez-vous lancer? | < 6 mois |
| Pourquoi une étude? | Besoin réel, pas curiosité |

### Script de Qualification

```
Bonjour, merci de m'avoir contacté.

Pour mieux vous aider, j'ai quelques questions:

1. Pouvez-vous me décrire votre projet en 2-3 phrases?

2. Quel est le budget que vous envisagez d'investir?

3. Avez-vous déjà travaillé dans ce domaine?

4. Avez-vous trouvé un local?

5. Quand souhaitez-vous lancer votre activité?

6. Pourquoi pensez-vous avoir besoin d'une étude de faisabilité?

Merci. Je peux vous proposer [Diagnostic/Pré-faisabilité/Étude complète].
```

### Décision

| Résultat | Action |
|----------|--------|
| **Qualifié** | Passer à la fiche client |
| **Non qualifié** | Orienter vers autre service |
| **Incertain** | Proposer un Diagnostic Express |
