## 1. DIAGNOSTIC EXPRESS

### Objectif
Tester rapidement la viabilité d'une idée sans investir dans une étude complète.

### Public Cible
- Porteurs de projets en phase d'idéation
- Entrepreneurs qui veulent une réponse rapide
- Clients hésitant entre plusieurs options

### Contenu (3-5 pages)

| Section | Contenu |
|---------|---------|
| **Résumé** | Idée, marché cible, potentiel |
| **Demande** | Estimation de la demande locale (1 page) |
| **Concurrence** | 5-8 concurrents identifiés |
| **Risques** | 3 risques majeurs identifiés |
| **Profitabilité** | Estimation rapide du CA et marge |
| **Recommandation** | Go / No-Go / Étudier davantage |

### Méthode
1. Consultation téléphonique (15 min)
2. Recherche en ligne (CNRC, Google, réseaux)
3. 2-3 appels pour vérifier la demande
4. Rédaction du diagnostic
5. Présentation orale (30 min)

### Prix
- **Diagnostic Express:** 3,000 DZD
- **Avec recommandation détaillée:** 5,000 DZD

### Conversion
- 30% des clients passent à la Pré-faisabilité
- 15% passent directement à l'Étude Complète

## 2. PRÉ-FAISABILITÉ

### Objectif
Fournir assez d'information pour décider si une étude complète est justifiée.

### Public Cible
- Porteurs de projets avec une idée claire
- Entrepreneurs qui cherchent du financement initial
- Ceux qui veulent valider leur concept

### Contenu (10-15 pages)

| Section | Contenu |
|---------|---------|
| **1. Présentation du projet** | Description, objectifs, porteur |
| **2. Marché** | Demande, concurrence (10 observ.), 3 scénarios |
| **3. Technique** | Équipements (1-2 devis), localisation |
| **4. Légal** | CNRC, autorisations, régime fiscal |
| **5. Finance** | Investissement, cash-flow annuel, seuil rentabilité |
| **6. Décision** | Risques, conditions, recommandation |

### Méthode
1. Consultation (1 heure)
2. Fiche d'information remplie
3. Recherche marché (CNRC, visites)
4. 5-10 entretiens clients
5. Modèle financier simplifié
6. Rédaction du rapport
7. Présentation (1 heure)

### Prix
- **Pré-faisabilité:** 8,000 DZD
- **Avec modèle Excel:** 10,000 DZD

### Conversion
- 50% des clients passent à l'Étude Complète
- 25% passent au Dossier Bancaire

## 3. ÉTUDE COMPLÈTE

### Objectif
Fournir toutes les informations nécessaires pour lancer, financer ou louer un projet.

### Public Cible
- Porteurs de projets prêts à investir
- Entrepreneurs qui cherchent un financement bancaire
- Ceux qui veulent une analyse approfondie

### Contenu (25-35 pages)

| Module | Pages | Contenu |
|--------|-------|---------|
| **1. Preuve Marché** | 5-8 | Demande, concurrence (15-20), entretiens, scénarios |
| **2. Plan Technique** | 4-6 | Équipements (2-3 devis), localisation, flux, maintenance |
| **3. Cadre Légal** | 3-5 | CNRC, autorisations, fiscalité, coûts |
| **4. Modèle Financier** | 6-10 | Investissement, cash-flow mensuel, DSCR, sensibilité |
| **5. Décision** | 1-2 | Risques, conditions, Go/No-Go |

### Annexes
- Fiche d'information client
- Registre des hypothèses
- Notes d'entretiens
- Photos/observations
- Devis fournisseurs

### Méthode
1. Consultation approfondie (1h30)
2. Collecte données (3-5 jours)
3. Validation marché (visites, entretiens)
4. Modèle financier complet
5. Contrôle qualité interne
6. Revue client
7. Rapport final
8. Présentation (1h30)

### Prix
- **Étude Complète:** 15,000 DZD
- **Avec modèle Excel + plan d'action:** 20,000 DZD
- **Avec présentation pitch:** 22,000 DZD

### Conversion
- 60% des clients demandent le Dossier Bancaire
- 40% souscrivent à la Mise à Jour Annuelle

## 4. DOSSIER BANCAIRE

### Objectif
Transformer une étude de faisabilité en dossier prêt pour une demande de financement bancaire.

### Public Cible
- Entrepreneurs qui demandent un prêt bancaire
- Porteurs de projets qui cherchent des investisseurs
- Ceux qui ont besoin d'un dossier professionnel

### Contenu

| Composant | Description |
|-----------|-------------|
| **Note Synthèse** | 2-3 pages, résumé exécutif pour le banquier |
| **Plan de Financement** | Détail des besoins et sources |
| **Analyse de Capacité de Remboursement** | DSCR, ratios financiers |
| **Calendrier de Remboursement** | Tableau d'amortissement |
| **Annexes** | Étude complète, justificatifs |

### Méthode
1. Analyse de l'étude existante
2. Restructuration pour format bancaire
3. Ajout des calculs de capacité
4. Rédaction de la note synthèse
5. Revue avec le client
6. Livraison

### Prix
- **Dossier Bancaire:** 12,000 DZD
- **Avec présentation bancaire:** 15,000 DZD

### Valeur Ajoutée
- Format adapté aux exigences bancaires algériennes
- Calculs de DSCR et ratios
- Note synthèse professionnelle
- Prêt pour dépôt
